# Animal-Shelter-and-Adoption-Management-System

A web application for managing shelter animals, adoption applications,
medical records, appointments, and animal status transitions.

## Technology Stack

### Client

- React
- Vite
- JavaScript

### Server

- Node.js
- Express
- SQLite
- better-sqlite3
- bcrypt
- JSON Web Tokens

## Run the Client

```bash
cd client
npm install
npm run dev
